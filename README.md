# 🌤️ WEATHER-API - Servicio Web de Consulta Meteorológica

## 📄 Descripción del Proyecto
**WEATHER-API** es una aplicación backend diseñada para la integración y consumo de servicios web meteorológicos en tiempo real. El sistema realiza peticiones HTTP a APIs RESTful externas, procesa las respuestas en formato JSON y gestiona la lógica para la entrega de datos climáticos estructurados de manera eficiente.

---

## 🛠️ Tecnologías y Herramientas Utilizadas
* **Lenguaje de Programación:** Python / JavaScript *(ajusta según el lenguaje usado)*.
* **Consumo de APIs RESTful:** Integración con proveedores de datos meteorológicos externos.
* **Formato de Datos:** JSON (*JavaScript Object Notation*) para la serialización y desestructuración de información.
* **Control de Versiones:** Git y GitHub para la gestión del código fuente.

---

## 🚀 Funcionalidades Principales
* **Peticiones Asíncronas/Síncronas:** Consulta de variables meteorológicas (temperatura, humedad, condiciones climáticas) en tiempo real por ubicación.
* **Procesamiento de Respuestas:** Manipulación y filtrado de la carga útil (*payload*) en JSON para extraer únicamente los parámetros relevantes.
* **Manejo de Excepciones:** Control de errores en peticiones HTTP (códigos de estado `404`, `500`, fallos de red) para asegurar la estabilidad del servicio.
